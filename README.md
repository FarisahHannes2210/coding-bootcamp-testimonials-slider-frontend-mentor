### What I learned

For this project, I learned of using grid-template-rows to arrange the contents in mobile screen size.

```css
.contents{
    display: grid; 
    width: 100vw;
    height: 100vh;
    grid-template-rows: 1fr 1fr;
    gap: 25px;
    justify-content: center;
    align-items: center;
    /* top: 0px; */
    text-align: center;
    /* border: 2px solid var(--DarkBlue); */
    /* width: 370px; */

}
```
